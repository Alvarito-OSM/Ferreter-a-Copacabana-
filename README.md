# Ferretería Copacabana - Sistema de Gestión e Inventario

Sistema de gestión e inventario para ferretería, desarrollado para administrar productos, ventas, compras, clientes, proveedores y empleados.

## Descripción

Este sistema permite:
- Gestión de productos y categorías
- Control de inventario con alertas de stock mínimo
- Registro de ventas y compras
- Gestión de clientes y proveedores
- Registro de pagos (efectivo, tarjeta, transferencia)
- Reportes de ventas y productos más vendidos

## Actores del sistema

| Actor | Rol |
|-------|-----|
| Administrador | Acceso total al sistema |
| Empleado | Ventas, clientes, consulta de stock, pagos |
